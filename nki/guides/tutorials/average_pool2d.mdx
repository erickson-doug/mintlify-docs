In this tutorial we examine a case of dimensionality reduction. We implement a 2D AveragePool operation, which is used in many vision neural networks. In doing so, we learn about:

- NKI syntax and programming model
- Multi-dimensional memory-access patterns in NKI

The 2D AveragePool operation takes `C x [H, W]` matrices and reduces each matrix along the `H` and `W` axes. To leverage free-dimension flexible indexing, we map the `C` (parallel) axis to the `P` dimension and the `H`/`W` (contraction) axes to the `F` dimension. Performing such a 2D pooling operation requires a 4D memory-access pattern in the `F` dimension, with reduction along two axes. The figure below illustrates the input and output tensor layouts.
