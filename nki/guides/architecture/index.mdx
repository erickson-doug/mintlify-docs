NKI currently supports the following NeuronDevice generations:

- Trainium/Inferentia2, available on AWS `trn1`, `trn1n`, and `inf2` instances.
- Trainium2, available on AWS `trn2` instances and UltraServers.
- Trainium3, available on AWS `trn3` instances and UltraServers.

The documents below provide an architecture deep dive of each NeuronDevice generation, with a focus on areas NKI developers can directly control through kernel implementation.

- [Trainium/Inferentia2 architecture](/nki/guides/architecture/trainium_inferentia2_arch) — Foundational architecture guide for understanding the basics of any NeuronDevice generation.
- [Trainium2 architecture](/nki/guides/architecture/trainium2_arch) — Walks through the architecture enhancements compared to the previous generation.
- [Trainium3 architecture](/nki/guides/architecture/trainium3_arch) — Covers the enhancements for the next-generation Trainium ML accelerators.

We recommend new NKI developers start with the Trainium/Inferentia2 architecture guide before exploring newer NeuronDevice architecture.
